# 考研自律钟（亮屏限时提醒）

每次手机亮屏解锁，就弹出「这次打算刷多久」的滚动选择（1–60 分钟，每 2 分钟一档）；
到点后 **震动 + 全屏图片悬浮提醒**，点一下图片 **自动锁屏**，帮你管住刷抖音/看小说的手。

> 面向考研复习的自我管理小工具，纯本地运行，无任何联网。

---

## 功能一览

| 功能 | 说明 |
|---|---|
| 亮屏触发 | 每次解锁进入手机 → 自动弹出滚动时长选择（档位 1/3/5/…/59/60 分钟，默认记住上次选择） |
| 后台倒计时 | 期间随意刷抖音/看小说，前台服务保活，不被打断；通知栏显示剩余时间 |
| 到点提醒 | 震动 + 半透明全屏悬浮窗图片（浮在任意 App 最上层，想忽略都难） |
| 自动锁屏 | 点一下提醒图片 → 自动锁屏，强制放下手机 |
| 中途息屏 | 本轮直接结束（记为「未完成」），下次亮屏重新弹选择 |
| 统计 | 记录每天开始轮数 / 完成数 / 实际用时，可回看近 7 天 |
| 自定义图片 | App 内可直接从相册更换提醒图片（不替换也没关系，内置占位图） |
| 开机自启 | 重启手机后自动恢复监测 |

## 一、准备工具（只需做一次）

1. 一台 Windows / macOS 电脑。
2. 安装 **Android Studio**（免费）：
   - 官网下载：https://developer.android.com/studio （国内访问慢的话搜「Android Studio 国内镜像下载」）
   - 一路默认安装即可，首次启动会询问是否下载 SDK 组件，**保持默认并完成**（约 10 分钟，需联网）。
3. Android 手机：安卓 8.0 及以上（2017 年后出的手机基本都满足）。

> 💡 **如果电脑不方便装 Android Studio**（比如只有手机、或电脑没网），
> 可以直接跳到文末 **「六、云端自动编译」**，或用 U 盘/微信把本文件夹拷到任何一台能上网的电脑上编译——装好 Android Studio 后总耗时 15 分钟左右。

## 二、打开工程并首次编译

1. 把整个 `手机管理程序` 文件夹拷贝到电脑上（路径别带中文或空格更稳，例如 `D:\kaoyan-timer`）。
2. 打开 Android Studio → **File → Open** → 选择本文件夹里的 `settings.gradle` → OK。
3. 首次打开会自动下载 Gradle 8.7 和依赖（走了国内镜像，一般几分钟）。右下角进度走完、没有红字即可。

> ⚠️ **如果报错 `Could not find or load main class org.gradle.wrapper.GradleWrapperMain`**（wrapper 的 jar 因为网络原因没随工程一起给你）：
> 1. 在 Android Studio 里 **File → New → New Project** 随便建一个空工程（模板会自动生成 `gradle/wrapper/gradle-wrapper.jar`）；
> 2. 在该空工程里找到 `gradle\wrapper\gradle-wrapper.jar`，复制；
> 3. 粘贴覆盖到本项目同路径 `gradle\wrapper\` 下；
> 4. 回到本项目，点 **File → Sync Project with Gradle Files**（或按 `Ctrl+Shift+O`）。
>
> 只要 jar 存在，后续所有依赖都会自动从镜像下载，不会再麻烦。

4. 菜单 **Build → Build APK(s)**，编译完成后右下角提示 `app-debug.apk` 生成位置
   （一般是 `app\build\outputs\apk\debug\app-debug.apk`）。
   > 也可以直接点顶部绿色 ▶ Run，用 USB 数据线连接手机自动安装调试，更快。

## 三、装到手机并开启权限（约 2 分钟）

把 `app-debug.apk` 传到手机（微信文件传输助手 / QQ / USB 拷贝都行），点击安装。
首次安装如提示「未知来源」，允许即可。

安装后打开 **考研自律钟**，按顺序点 4 个按钮授权：

1. **悬浮窗权限** → 去开启（系统会跳转，把开关打开）。没有它，到点的图片弹不出来。
2. **锁屏管理** → 去激活 → 激活。没有它，点完图片不会自动锁屏。
3. **忽略电池优化** → 去开启（防止国产手机把计时服务杀掉）。
4. **通知权限** → 去开启（用于显示剩余时间）。

> 💡 部分国产手机（小米/华为/vivo/OPPO）还会问「允许自启动/后台运行」，全部允许即可；
> 若之后发现不再自动弹选择，多半是后台被限制了，回本页看权限状态是否变回「去开启」。

### 🎯 iQOO Neo 9（vivo OriginOS）防杀后台专属设置

iQOO 的省电策略非常激进，**做完下面 4 步**后基本不会被杀（本应用另有「20 分钟自检复活」兜底，就算被杀也会自动复活，只是复活前那一两轮可能漏提醒）：

1. **自启动**：设置 → 应用与权限 → 应用管理 → 找到「考研自律钟」→ 权限 → 自启动 → **允许**
2. **后台高耗电**：设置 → 电池 → 后台耗电管理 → 「考研自律钟」→ 选 **允许后台高耗电**（别选智能/不允许）
3. **最近任务锁定**：打开 App 后，从屏幕底部上滑呼出最近任务，**按住「考研自律钟」卡片下拉**（出现锁图标即锁定，被清理时会被跳过）
4. **忽略电池优化**：App 内第三个权限按钮一键开启（上面的引导里已包含）

> 做完后建议重启一次手机再验证：锁屏 → 亮屏应弹出选时长界面。

## 四、怎么用

1. 右上角总开关保持打开；
2. 按一下电源键 **息屏 → 再亮屏解锁**，就会弹出「这次打算刷多久？」；
3. 滚动选 **1、3、5…59、60 分钟** → **开始计时**（只有点「开始计时」才能关闭弹窗；点屏幕其它地方无效。急用手机可按电源键息屏结束本轮，下次亮屏会再弹）；
4. 放心刷抖音/看小说，通知栏显示剩余时间；
5. 到点：震动 + 图片铺满屏幕 → **点一下屏幕 → 自动锁屏**，手机被锁，乖乖回去学习；
6. 再次亮屏解锁，新一轮又开始了。

主界面可查看：今日开始几轮 / 完成几轮 / 实际用时，以及近 7 天记录。

**更换提醒图片**：主界面 → 到点提醒图片 → 从相册更换（选一张能激励你放下手机的照片）。
这样以后你找到满意的图片自己换就行，**完全不用重新编译**。

## 五、常见问题

| 问题 | 处理 |
|---|---|
| 打开工程一直下载/报网络错误 | 确认电脑能联网；依赖走的是阿里云/腾讯镜像，极少失败 |
| 编译报错看不懂 | 把红色错误信息截图发我，我来帮你看 |
| 安装到手机提示「已安装应用与设备不兼容」 | 手机安卓版本低于 8.0，暂不支持 |
| 装上后锁屏再亮屏不弹选择 | 检查主界面 4 个权限是否都已开启；iQOO/vivo 按「三」的专节再做 4 步 |
| 桌面图标是什么样 | 蓝底白色时钟的「考研自律钟」图标，安装后自动出现在桌面；App 内置自适应图标，无需额外设置 |
| 会不会被系统杀掉后台 | 已内置两层防护：常驻前台服务 + 20 分钟闹钟自检复活；配合 iQOO 专节设置后基本不掉线 |
| 想彻底关掉 | 主界面右上角开关关掉即可，不影响正常使用手机 |
| 想卸载 | 卸载前请先在主界面「锁屏管理」里取消激活（或系统设置-安全-设备管理器中移除），否则可能卸不掉 |
| 到点锁屏了还想再玩 | 自律工具只能帮到这儿了，剩下的交给你的考研意志 😄 |

## 六、（可选）云端自动编译：电脑不用装 Android Studio

工程里已带好 `.github/workflows/build-apk.yml`。如果你能访问 GitHub：

1. 到 github.com 注册/登录，新建一个仓库（Public/Private 都行，别勾选任何初始化文件）；
2. 把本工程所有文件上传进仓库（网页可直接拖拽上传文件夹内容）；
3. 打开仓库 **Actions** 页 → 左侧选中 **Build APK** → 右侧 **Run workflow**；
4. 约 3–5 分钟后刷新页面，进入该次运行，底部 **Artifacts** 处下载 `kaoyan-timer-apk.zip`，解压出 `app-debug.apk` 即可发到手机安装。

> 电脑/手机不在同一网络时，用微信「文件传输助手」或 QQ 把 APK 发到自己手机最方便。

## 技术备注（开发者可看）

- 纯 Java + Android 平台 API，零第三方依赖，`minSdk 26 / target 33 / compile 34`。
- 亮屏监听：前台服务动态注册 `ACTION_SCREEN_ON / SCREEN_OFF / USER_PRESENT`。
- 防杀后台：AlarmManager 20 分钟自检闹钟，进程被杀后由 `SelfCheckReceiver` 自动拉起并续订下一次（链条不依赖 App 存活）。
- 后台弹界面依赖「悬浮窗权限」（Android 10+ 后台启动 Activity 的豁免条件之一）。
- 锁屏用设备管理员 `DevicePolicyManager.lockNow()`，无任何数据管理策略。
- 统计存本地 SQLite（`stats.db`），不上传任何数据。
